## Deep Learning — Goodfellow, Bengio & Courville (2017)

This repository contains my personal notes and chapter-by-chapter summaries for the book "Deep Learning" by Ian Goodfellow, Yoshua Bengio, and Aaron Courville (MIT Press, 2017). I'm reading the book and will add summaries and reflections as I progress through the chapters.

Brief introduction:

- The book is a comprehensive introduction to modern deep learning, covering mathematical foundations, network architectures, optimization and regularization techniques, convolutional and sequence models, representation learning, and deep generative models.
- It balances theory and practice and is well-suited for graduate students, researchers, and practitioners who already have a basic background in linear algebra, probability, calculus, and machine learning.
- Expect rigorous explanations, useful derivations, and pointers to important research. Some chapters are mathematically dense; take your time working through the exercises and derivations.

How I will use this repo:

- **Chapter Summaries:** Short markdown files summarizing each chapter's key ideas, important equations, and personal notes or questions.
- **Examples & Notes:** Code snippets, experiments, or toy examples that help illustrate concepts from the book.
- **References:** Links to important papers mentioned in the book or that I find helpful while studying.

Suggested summary format and filename convention:

I recommend keeping summaries in a `summaries/` folder with filenames like `01-introduction.md`, `02-linear-algebra.md`, etc. Each summary can follow this template:

```
# Chapter X — Chapter Title

- **Date:** YYYY-MM-DD
- **Key concepts:** One-line bullets of the main ideas
- **Important equations / derivations:** Short list
- **Examples / intuition:** Practical explanations or sketches
- **Questions / TODOs:** Things to revisit or experiment with

Short summary paragraph (3-6 lines).

Further reading / references
```
